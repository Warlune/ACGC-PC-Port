# Live original / pack texture comparison

Press F6 to cycle Original → Current pack → Everything 4x. Graphics → Texture source selects each directly; Settings → Image → Texture source offers the same choices in-game. The choice persists as `texture_replacements = 0/1/2` in settings.ini. The title bar reports ORIGINAL, PACK or EVERYTHING 4X. F6 is reserved except during keybinding capture; while editing pending in-game settings, apply/discard those edits or use the Texture source row.

On first encounter with a texture, the cache uploads the original and looks up/uploads its replacement. Both stay available until normal cache eviction. Everything mode uses the pack where matched and generates a 4x fallback for unmatched decoded textures on demand. It reads the original RGBA upload, applies Scale2x twice with clamp/repeat/mirror addressing, and retains the result until eviction. It handles characters, fonts, menus and dynamic palettes without requiring offline asset enumeration. Fallbacks preserve exact input RGBA values; this is edge-preserving filtered scaling, not AI reconstruction. EFB captures use their existing full-resolution path. Allocation failure retains the original rather than crashing. First-time generation adds work and GPU memory; warm switches reuse all resident variants. No mode changes resolution/filtering/camera settings. Pack mode keeps originals for unmatched textures.

Original and runtime textures are owned by the normal texture cache. Pack replacements remain owned by the pack loader. Sampler changes update all resident variants. EFB captures remain untouched. Mode changes run between presented frames for the F6 and native-menu paths, flushing any pending draws before rebinding active texture slots.

Validation: `pc/tests/texture_compare_smoke.c` exercises the actual decoder/cache against a deterministic pack fixture on the OpenGL driver. It verifies resident original/HD textures and pixel data, 20 switches with no extra lookups/decode misses, immediate bound-slot switching, sampler parity, missing-replacement fallback and texture ownership. See `docs/texture-compare-smoke.log`. Full-game UI validation is recorded separately in `texture-toggle-validation.json`.
