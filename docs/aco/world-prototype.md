# Three-town development preview

The opt-in `ACO_DEV_EAST` build (legacy internal option name, defaults OFF) uses 21 columns: a complete newly generated seven-column west town, the original seven-column center town, and a newly generated seven-column east town. Each town retains its mountain borders, native beaches/ocean, railway, river, cliffs, bridges and landmark placements. There is no custom tunnel or passage between the towns. Duplicate stores/stations/landmarks are intentional for this prototype.

`pc/tools/generate_dev_town.c` links the original `m_random_field_ovl.c`, combination table and native RNG at the original 7x10 dimensions. Its small river-direction adapter matches the lookup in `m_random_field.c`. Different saved seeds generate the two sides. Do not run the generator against the widened client dimensions: the game's authored base templates are seven columns wide. The assembly tool copies the corresponding native foreground templates directly from `fgdata.bin` on the user's local disc; these are real generated layouts, not mirrored copies or hand-painted grass.

`tools/aco/make-world-preview.py` assembles the generated sides around a copy of a normal GAFE01 save. It validates source/output checksums, preserves all 30 original foreground acres and buried-item flags byte-for-byte at a seven-acre eastward offset, copies the fixed fields around resized arrays, and mirrors the main save into its backup sector. It refuses to overwrite an output or edit the source. Expanded saves are 548928 bytes, **not standard GameCube saves**. Layout JSON comes from compiling `pc/tools/dev_east_layout.c` with and without the development define. Keep this runtime/save directory isolated from normal builds.

`Build World Dev.cmd` builds the client. Launch with `--dev-world`, optionally `--dev-west` or `--dev-east`. The dev boot chooses an existing resident, enables the RTC normally initialized by the title, skips character/title setup, and chooses an empty tile on a flat acre in the selected region. Every restart reuses that resident. Resetti is disabled and continuous acre movement enabled in the dev copy.

This is a terrain/layout preview. Global town services, NPCs, landmark uniqueness, original map-panel labels, schedules/train service and world metadata still assume one logical town. Duplicated buildings are not independent fully integrated businesses. Story locks, connections between the maps, co-op integration and the actual overhead-rendered minimap remain further work. The faint illustrated minimap displays the widened world.
